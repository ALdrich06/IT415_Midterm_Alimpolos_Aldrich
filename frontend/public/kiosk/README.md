# Kiosk visual assets

Generated using the built-in imagegen tool. Payment illustrations and the logo have transparent backgrounds; the cafe backdrop is opaque. The decorative QR motif is not a payment code. The actual payment QR flow is unchanged.

These assets use the existing cream, maroon and gold cafe palette. Next Image displays the illustrations with object-contain. Background decoration is scoped to the kiosk and hidden when printing receipts.
